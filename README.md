# YouTube Watch Sync – releases

Signed Firefox builds of YouTube Watch Sync (watch YouTube in sync with friends). Source code lives in a private repository; this repo only distributes the signed builds and the update feed.

## Install
Use Firefox 142 or newer (desktop or Android). Open the [latest release](../../releases/latest) and click the `.xpi` file; Firefox asks to confirm. Updates then arrive automatically.

## Use
Open a YouTube video, click the toolbar icon, **Create room**, and send the code to friends. They open any YouTube page, click the icon, and **Join**.
